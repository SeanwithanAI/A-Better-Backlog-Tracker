Retro handheld playtime (Cocoon)

Cocoon times every game you play. Its backups carry that history, so the tracker can add each play session to your log. Only new sessions are added, so bringing in the same backup twice is safe.

In Cocoon, make a backup (it saves a cocoon_backup_….zip file), then choose it here.

Steam playtime

Pulls your Steam library and playtime. Each sync compares against the last one and adds the new hours to your play log automatically. Backlog games you've started playing move to Playing.

Get a key at steamcommunity.com/dev/apikey (any domain name works). Your SteamID64 is the long number in your profile link, or look it up at steamid.io. In Steam's privacy settings, Game details must be Public.

Automatic through PageVault. Your PageVault server fetches your Steam playtime for you, each time you open the tracker (at most every 30 minutes). New hours go into your play log with the day you last played. No proxy or copying needed.

Steam doesn't let web pages read its data directly. With a proxy, Steam syncs on its own each time you open the tracker (at most every 30 minutes) and SteamGridDB box art works too. Without one, use Sync now and the two-step method below.

How to get a proxy (free, about 5 minutes)

A proxy is a tiny web service that asks Steam and SteamGridDB for you, because they don't answer web pages directly. The easiest free one is your own Cloudflare Worker:

  1. Sign up for free at cloudflare.com (no card needed).
  2. Go to Workers & Pages, tap Create, start from the Hello World template, and tap Deploy.
  3. Tap Edit code, replace everything with the code below (Copy code), then tap Deploy.
  4. Copy your Worker's address (it ends in workers.dev), add /?url={url} to the end, and paste it in the proxy box above. Example: https://backlog-proxy.yourname.workers.dev/?url={url}

This Worker only passes along Steam and SteamGridDB requests, so nobody else can use it for anything else. Don't use a public proxy you find online: your Steam and SteamGridDB keys would pass through someone else's server.

// A Better Backlog Tracker: tiny proxy for Steam and SteamGridDB (Cloudflare Worker)
export default {
  async fetch(req) {
    const cors = {'Access-Control-Allow-Origin': '*', 'Access-Control-Allow-Headers': 'Authorization', 'Access-Control-Allow-Methods': 'GET, OPTIONS'};
    if (req.method === 'OPTIONS') return new Response(null, {headers: cors});
    const url = new URL(req.url).searchParams.get('url') || '';
    if (!/^https:\/\/(api\.steampowered\.com|www\.steamgriddb\.com)\//.test(url)) return new Response('Only Steam and SteamGridDB addresses are allowed.', {status: 403, headers: cors});
    const auth = req.headers.get('Authorization');
    const r = await fetch(url, {headers: auth ? {Authorization: auth} : {}});
    const headers = new Headers(r.headers);
    for (const [k, v] of Object.entries(cors)) headers.set(k, v);
    return new Response(r.body, {status: r.status, headers});
  }
};

Already run a server (like a NAS)? Any CORS proxy works, for example cors-anywhere: enter its address, like http://your-server:8080/.
